PDOS is interpolated linearly between samples and integrated at the exact window boundaries. No extrapolation is used. A window beyond the data is marked “Incomplete range”. The combined center requires both spins. The spin filter affects every panel and the active-panel table.

How to use this viewer
  1. Click Load PDOS files and select one or multiple TXT or CSV files. Up/down partners are paired from their filenames.
  2. Select the active panel, then tick its datasets and orbitals. Use All 5 d orbitals for individual curves, or Sum d for their sum and d-band center.
  3. Click Add to copy the current panel, then change its title, datasets or orbitals. Set Columns to arrange the panels.
  4. Set the shared energy Min/Max. Set the active panel's Y limit (±), or leave it blank for automatic symmetric limits.
  5. Select both spins, up only, or down only. This filter applies to all panels. Spin-up is solid; spin-down is dashed and mirrored below zero.
  6. Read band centers below the plot for the active panel. Export XLSX saves the same rows, columns and five-decimal values, plus a Settings sheet.
  7. For images, choose Export SVG, or set PNG DPI and width in cm before Export PNG. Legends are included. Height follows the figure's aspect ratio.

Energy reference: the Eꜰ = 0 checkbox changes the axis label and reference line only. It does not subtract a Fermi energy. Shift energies before loading if needed. No smoothing or normalization is applied. PDOS units are assumed to be states/eV.

Local processing: selected data are read in your browser and are not uploaded by this viewer. Reloading or closing the page clears loaded files and panel settings. No experimental or DFT data are embedded in this release.

Required file formats and examples

Filename: PDOS-ATOM-SYSTEM-up.txt or PDOS-ATOM-SYSTEM-dw.txt. CSV uses the same name with .csv. Example: PDOS-Nb-NbHCl-up.csv. Use dw for spin-down. ATOM cannot contain a hyphen; SYSTEM may contain hyphens. Matching is case-sensitive for atom/system names.

.txt = whitespace-delimited: separate columns with one or more spaces or tabs. .dat is also accepted with this format.

#Energy s py pz px dxy dyz dz2 dxz dx2 tot
-1.0    0.10 0 0 0 0.20 0.10 0.30 0.10 0.20 1.00
 0.0    0.05 0 0 0 0.10 0.05 0.15 0.05 0.10 0.50
 1.0    0.02 0 0 0 0.04 0.02 0.06 0.02 0.04 0.20

.csv = comma-delimited: use commas, not spaces or semicolons. Use a decimal point, not a decimal comma. Quoted fields are accepted; multiline fields are not.

Energy,s,py,pz,px,dxy,dyz,dz2,dxz,dx2,tot
-1.0,0.10,0,0,0,0.20,0.10,0.30,0.10,0.20,1.00
0.0,0.05,0,0,0,0.10,0.05,0.15,0.05,0.10,0.50
1.0,0.02,0,0,0,0.04,0.02,0.06,0.02,0.04,0.20

These are synthetic format examples, not research results. Energy must be the first column and strictly increasing, with at least two numeric rows. #Energy or Energy is required. Blank cells, NaN, infinity and repeated energies are rejected. Blank lines and comment lines beginning with # are ignored. Scientific notation (E or D) is supported.

Use any subset of the listed orbital columns, in any order after Energy. For example, an H-s file needs only Energy s (TXT) or Energy,s (CSV). Sum d requires dxy, dyz, dz2, dxz and dx2; Sum p requires px, py and pz. Missing orbitals are skipped with a message. The tot column is read as supplied, not recomputed.

dz2 means d(z²); dx2 means d(x²−y²). Use consistent signs within each spin file. Down-spin values may be positive or already negative; both are converted to positive magnitudes for band-center integration. Loading another file with the same atom, system and spin replaces that channel, even if its extension differs.

Publish on GitHub Pages
  1. Create a public GitHub repository, for example pdos-viewer.
  2. Upload this HTML file as index.html at the repository root. The ready-to-upload ZIP also contains a README and synthetic format examples. Extract the ZIP first; do not upload the ZIP as the website.
  3. Open Settings → Pages. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
  4. Check the Actions tab for the Pages deployment. Your project URL will normally be https://YOUR-USERNAME.github.io/pdos-viewer/. GitHub may take up to 10 minutes to publish updates.
  5. To update, replace index.html on the same branch and commit. Refresh the site after deployment finishes.

No Python, Streamlit, server, API key or build command is required. Only files committed to the repository are published; selecting local PDOS files in the viewer does not commit or upload them.

Official instructions: GitHub Pages quickstart and Configure a publishing source.
